# Excel Insight

基于 Python、Flask 和 Pandas 开发的 Excel 销售数据分析 Web 应用。

## 功能

- 上传并检查 XLSX 销售数据
- 校验必需字段、数量和单价的空值及数值类型
- 计算总销售额和平均每单销售额
- 在网页上展示前 5 行数据预览
- 区分业务校验错误和内部处理异常，避免向用户暴露内部错误详情
- 使用 pytest 进行自动化测试

## Excel 文件要求

上传文件需为有效的 `.xlsx` 文件，且至少包含以下列：

| 列名 | 要求 |
| --- | --- |
| `order_id` | 订单编号 |
| `order_date` | 订单日期 |
| `product` | 商品名称 |
| `quantity` | 非空数值 |
| `unit_price` | 非空数值 |

可以包含额外列。单次上传请求上限为 **5MiB（5,242,880 字节）**，其中包含 multipart 表单开销，因此文件本身需略小于此值。空工作表、缺少必需字段或数量、单价数据无效时，页面会显示对应的中文校验提示。

## 分析规则

- 每行销售额 = `quantity × unit_price`
- 总销售额 = 各行销售额之和
- 平均每单销售额 = 总销售额 ÷ 订单行数，结果保留两位小数
- 订单数为 0 时平均值使用 `0.00`，避免除零；空工作表仍会按数据校验规则拒绝
- 分析成功后展示订单数量、总销售额、平均每单销售额及前 5 行预览

## 错误处理与日志

业务数据校验错误使用 `DataValidationError` 携带结构化校验信息，页面显示可理解的中文提示。普通 `ValueError` 及其他未预期异常会在服务端记录，并向页面返回通用错误提示，不直接展示异常文本或堆栈。日志不会记录上传数据行的完整内容。

## 安装依赖

```powershell
python -m pip install flask pandas openpyxl pytest
```

## 启动项目

```powershell
python app.py
```

浏览器访问：<http://127.0.0.1:5001>

## 运行测试

```powershell
python -m pytest -v
```

当前测试套件包含 13 项自动化测试，覆盖 Excel 读取与校验、分析结果、上传限制、文件结构检查和异常信息保护。

## 大文件上传样例

当前工作区生成的 `data/large_valid_sales_5mb.xlsx` 包含 5,000 笔订单，文件大小为 5,218,235 字节（约 5.22MB / 4.98MiB），用于验证接近 5MiB 上限的有效 XLSX 上传。该文件是本地测试样例，不属于应用运行所需文件。
